# Dewey Dash

Dewey Dash is a playful top-down library game for K-5 students. Students receive a call number from Ms. Maple, use the Dewey Decimal guide to find the correct broad section, pick up a book, and return it to the librarian.

## Run locally

```bash
bun install
bun run dev
```

The development server runs at `http://localhost:8000`.

## Check and build

```bash
bun run check
bun run build
```

## Controls

- Use the arrow keys or on-screen direction buttons to move.
- Press Space or Enter, or select the action button, to talk to Ms. Maple and pick up or return books.
- Select the `?` button to reopen the instructions.
